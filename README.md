# Blinkit Sales Dashboard - Power BI Project

## Overview
This Power BI dashboard analyzes Blinkit sales data and provides insights into outlet performance, item categories, and customer ratings.

## Tools Used
- Power BI
- Excel
- DAX

## Features
- Sales Analysis
- Outlet Performance
- Item Category Insights
- Interactive Filters

## Key Insights
- Tier 3 outlets generated highest sales
- Regular fat items had more sales
- Fruits and snacks were top-selling categories
